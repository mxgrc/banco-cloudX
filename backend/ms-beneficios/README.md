# Microservicio de beneficios

Base implementada: Categoria, Beneficio, repositorios JPA y 10 pruebas.
Propietario de categorías y beneficios. Services/DTO/Controllers pendientes.

ADMIN crea beneficios, asigna categorías y lista todos los beneficios.
CLIENTE activo consulta los beneficios disponibles para inscripción.

Datos mínimos propuestos: beneficio (id, nombre, descripción, descuento,
categoría y disponibilidad); categoría (id y nombre). La categoría tendrá
varios beneficios. Descuento porcentual mayor que 0 y hasta 100 con dos decimales.
Ver documentacion/fase6-persistencia.md en la raíz del backend.
